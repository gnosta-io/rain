# Rain Dashboard

A single-page rain dashboard for any US ZIP code: year-to-date rain against NOAA normals, CoCoRaHS gauges inside the ZIP, the Open-Meteo model, the NWS forecast and alerts, and live radar.

Everything runs in the browser from public data sources; there is no server or build step. Open `index.html` locally or view it on GitHub Pages.

Data: CoCoRaHS, Open-Meteo, NOAA normals via ACIS, National Weather Service, U.S. Census TIGERweb, RainViewer, Zippopotam.us. Map: Esri, HERE, Garmin, © OpenStreetMap contributors.
